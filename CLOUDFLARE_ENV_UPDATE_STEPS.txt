IF VARIABLES DON'T EXIST:
  1. Click "Add variable" button
  2. Enter variable name: VITE_API_URL
  3. Enter value: https://smartprint-6i2b.onrender.com/api
  4. Check "Production" environment
  5. Click "Save"
  6. Repeat for VITE_SOCKET_URL

IF STILL SEEING OLD URL AFTER REDEPLOY:
  1. Clear ALL browser data (not just cache)
  2. Try incognito/private window
  3. Check deployment logs in Cloudflare
  4. Verify env vars in deployment details
  5. Unregister service worker:
     navigator.serviceWorker.getRegistrations().then(r => 
       r.forEach(reg => reg.unregister())
     )

IF DEPLOYMENT FAILS:
  1. Check build logs in Cloudflare
  2. Verify your code builds locally: npm run build
  3. Check for syntax errors
  4. Try deploying again
